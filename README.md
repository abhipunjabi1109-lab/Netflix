# Netflix Titles Dataset Analysis

## 📌 Project Overview

This project is based on the Netflix Titles Dataset, which contains detailed information about movies and TV shows available on Netflix. The dataset is widely used for SQL practice, data analytics, exploratory data analysis (EDA), dashboard creation, and machine learning preparation.

The dataset includes information such as:

* Show ID
* Title
* Type (Movie / TV Show)
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Genre / Category
* Description

This project helps in understanding Netflix content trends, audience preferences, country-wise production, genre distribution, and platform growth over time.
